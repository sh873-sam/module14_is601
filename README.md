# Module 14 – Complete BREAD Functionality for Calculations API


# Project Overview

This project is a full-stack Calculations Application built with FastAPI, PostgreSQL, Docker, and GitHub Actions CI/CD.

The application supports complete BREAD functionality:

- Browse calculations
- Read a specific calculation
- Edit calculations
- Add new calculations
- Delete calculations

The application also includes:

- JWT Authentication
- Frontend dashboard
- Swagger API documentation
- Docker containerization
- GitHub Actions CI/CD pipeline
- Automated testing
